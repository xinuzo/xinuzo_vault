>[!tips] 3.29 Exponential Function
>$\exp(z) = e^x (\cos y + i \sin y)$ for $z = x + iy$.
>Periodic with period $2\pi i$.

>[!tips] 3.30 Logarithmic Function
>$\log z = \ln |z| + i \arg z$. This is a multiple-valued function.
>**Principal Branch**: $Log z = \ln |z| + i Arg z$ ($-\pi < Arg z < \pi$).
>A **branch** of a multiple-valued function is a single-valued function that is analytic in some domain (usually requiring a branch cut).

>[!tips] 3.32 Complex Exponents
>For $z \neq 0$ and complex $c$, $z^c = \exp(c \log z)$. This is generally multiple-valued.
>$Principal Value: P.V. z^c = \exp(c Log z)$.

>[!tips] 3.33 Trigonometric Functions
>$\sin z = \frac{e^{iz} - e^{-iz}}{2i}, \quad \cos z = \frac{e^{iz} + e^{-iz}}{2}$
>$\tan z = \sin z / \cos z$.

>[!tips] 3.35 Hyperbolic Functions
>$\sinh z = \frac{e^z - e^{-z}}{2}, \quad \cosh z = \frac{e^z + e^{-z}}{2}$
>Identity: $\cosh^2 z - \sinh^2 z = 1$.
>Relations: $\sinh(iz) = i \sin z, \cosh(iz) = \cos z$.
