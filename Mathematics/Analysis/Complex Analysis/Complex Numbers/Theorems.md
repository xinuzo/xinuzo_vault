>[!tips] 1.3 Properties of Field
>The set of complex numbers $\mathbb{C}$ forms a field under addition and multiplication (Commutative, Associative, Distributive, Identities 0 and 1, Inverses).

>[!tips] 1.4 Triangle Inequality
>For any complex numbers $z_1, z_2$:
>$$|z_1 + z_2| \le |z_1| + |z_2|$$
>Also: $||z_1| - |z_2|| \le |z_1 + z_2|$.

>[!tips] 1.5 Conjugate Properties
>$\overline{z_1 + z_2} = \bar{z}_1 + \bar{z}_2$
>$\overline{z_1 z_2} = \bar{z}_1 \bar{z}_2$
>$z \bar{z} = |z|^2$
>$Re(z) = (z + \bar{z})/2$, $Im(z) = (z - \bar{z})/(2i)$.

>[!tips] 1.8 Roots of Complex Numbers
>The $n$th roots of $z_0 = r_0 \exp(i\theta_0)$ are:
>$$c_k = \sqrt[n]{r_0} \exp\left(i \frac{\theta_0 + 2k\pi}{n}\right), \quad k = 0, 1, ..., n-1$$
