>[!tips] 4.39 Contour
>A **contour** (or piecewise smooth arc) is an arc consisting of a finite number of smooth arcs joined end to end.
>- **Simple Closed Contour**: A contour that does not intersect itself and starts/ends at the same point (Jordan curve).
>- **Positively Oriented**: Counterclockwise direction (interior is to the left).

>[!tips] 4.40 Contour Integral
>The integral of $f(z)$ along a contour $C$ parametrized by $z(t)$ ($a \le t \le b$) is:
>$$\int_C f(z) dz = \int_a^b f(z(t)) z'(t) dt$$

>[!tips] 4.44 Antiderivative
>A function $F(z)$ is an antiderivative of $f(z)$ on a domain $D$ if $F'(z) = f(z)$ for all $z \in D$.

>[!tips] 4.54 Simply Connected Domain
>A domain $D$ is simply connected if every simple closed contour within it encloses only points of $D$ (no "holes").
>- **Multiply Connected**: A domain that is not simply connected.
