>[!tips] 11.2 Ring and $\sigma$-ring
>A collection of sets $\mathscr{R}$ is a ring if it is closed under union and difference. It is a $\sigma$-ring if closed under countable union.

>[!tips] 11.4 Set Function
>A function $\phi: \mathscr{R} \to \mathbb{R}$. $\phi$ is additive if $\phi(A \cup B) = \phi(A) + \phi(B)$ for disjoint $A, B$. Countably additive if for disjoint unions.

>[!tips] 11.8 Measure and Measurable Sets
>Let $\mu^*$ be an outer measure on elementary sets. A set $A$ is $\mu$-measurable if it splits every set nicely. $\mu(A)$ is the Lebesgue measure of $A$.

>[!tips] 11.13 Measurable Function
>$f: X \to \mathbb{R}$ is measurable if $f^{-1}((a, \infty))$ is a measurable set for every real $a$.

>[!tips] 11.20 Lebesgue Integral
>For a simple function $s = \sum c_i \chi_{E_i}$, $\int s d\mu = \sum c_i \mu(E_i)$.
>For nonnegative $f$, $\int f d\mu = \sup \int s d\mu$ over simple $0 \le s \le f$.
>For general $f$, $\int f d\mu = \int f^+ d\mu - \int f^- d\mu$.
