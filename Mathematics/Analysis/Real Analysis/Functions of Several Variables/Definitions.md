>[!tips] 9.1 Linear Transformation
>A mapping $A: X \to Y$ (vector spaces) such that $A(\alpha x + \beta y) = \alpha Ax + \beta Ay$. The set of linear transformations is $L(X, Y)$.

>[!tips] 9.11 Differentiation in $\mathbb{R}^n$
>$f: E \subset \mathbb{R}^n \to \mathbb{R}^m$ is differentiable at $x$ if there exists $A \in L(\mathbb{R}^n, \mathbb{R}^m)$ such that
>$$\lim_{h \to 0} \frac{|f(x+h) - f(x) - Ah|}{|h|} = 0$$
>$A$ is denoted by $f'(x)$.

>[!tips] 9.16 Partial Derivatives
>$(D_j f_i)(x)$ is the derivative of the $i$-th component of $f$ with respect to the $j$-th coordinate.

>[!tips] 9.24 Contraction
>A mapping $\phi: X \to X$ where $d(\phi(x), \phi(y)) \le c d(x, y)$ with $c < 1$.
