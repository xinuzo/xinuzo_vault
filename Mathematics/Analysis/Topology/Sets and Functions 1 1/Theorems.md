

> [!theorem] Distributive Laws of Set Theory
> $$A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$$
> $$A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$$

> [!theorem] DeMorgan's Laws
> $$A - (B \cup C) = (A - B) \cap (A - C)$$
> $$A - (B \cap C) = (A - B) \cup (A - C)$$

> [!theorem] Lemma 2.1 (Bijectivity Criterion)
> Let $f: A \to B$. If there are functions $g: B \to A$ and $h: B \to A$ such that $g(f(a)) = a$ for every $a \in A$ and $f(h(b)) = b$ for every $b \in B$, then $f$ is bijective and $g = h = f^{-1}$.

> [!theorem] Lemma 3.1
> Two equivalence classes $E$ and $E'$ are either disjoint or equal.

> [!theorem] Theorem 4.1 (Well-ordering property)
> Every nonempty subset of $\mathbb{Z}_+$ has a smallest element.

> [!theorem] Theorem 7.1
> Let $B$ be a nonempty set. The following are equivalent:
> 1. $B$ is countable.
> 2. There is a surjective function $f: \mathbb{Z}_+ \to B$.
> 3. There is an injective function $g: B \to \mathbb{Z}_+$.

> [!theorem] Theorem 7.5
> A countable union of countable sets is countable.

> [!theorem] Theorem 7.7
> Let $X$ denote the two-element set $\{0, 1\}$. Then the set $X^\omega$ is uncountable.

> [!theorem] Theorem 7.8
> Let $A$ be a set. There is no injective map $f: \mathcal{P}(A) \to A$, and there is no surjective map $g: A \to \mathcal{P}(A)$.

> [!theorem] Axiom of Choice
> Given a collection $\mathcal{A}$ of disjoint nonempty sets, there exists a set $C$ consisting of exactly one element from each element of $\mathcal{A}$.

> [!theorem] Well-Ordering Theorem
> If $A$ is a set, there exists an order relation on $A$ that is a well-ordering.

> [!theorem] The Maximum Principle (Hausdorff)
> Let $A$ be a set; let $<$ be a strict partial order on $A$. Then there exists a maximal simply ordered subset $B$ of $A$.

> [!theorem] Zorn's Lemma
> Let $A$ be a set that is strictly partially ordered. If every simply ordered subset of $A$ has an upper bound in $A$, then $A$ has a maximal element.
