>[!tips] 8.1 P and NP
>**P**: Class of problems solvable in polynomial time.
>**NP**: Class of problems verifiable in polynomial time (nondeterministic polynomial).
>**NP-complete**: The hardest problems in NP; if one is solvable in P, all are.

>[!tips] 8.2 Polynomial Reduction
>A problem $P$ reduces to $Q$ if an instance of $P$ can be transformed into an instance of $Q$ in polynomial time such that the answers coincide.

>[!tips] 8.3 Satisfiability (SAT)
>Given a boolean formula, does there exist a truth assignment making it true? 3-SAT (clauses of size 3) is NP-complete.
