>[!tips] 16.1 Matching
>A set of pairwise non-adjacent edges.
>- **Perfect Matching (1-factor)**: A matching that covers every vertex.
>- **Maximum Matching**: A matching with the maximum possible number of edges.

>[!tips] 16.1 M-Alternating Path
>A path whose edges alternate between edges in $M$ and edges not in $M$.
>- **M-Augmenting Path**: An M-alternating path whose endpoints are unsaturated (not covered) by $M$.

>[!tips] 16.3 Factor
>A $k$-factor is a $k$-regular spanning subgraph.
