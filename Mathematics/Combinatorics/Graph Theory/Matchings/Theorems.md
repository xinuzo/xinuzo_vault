>[!tips] Theorem 16.1 Berge's Theorem
>A matching $M$ in $G$ is a maximum matching if and only if $G$ contains no $M$-augmenting path.

>[!tips] Theorem 16.4 Hall's Marriage Theorem
>A bipartite graph $G[X, Y]$ has a matching covering $X$ if and only if $|N(S)| \ge |S|$ for all $S \subseteq X$.

>[!tips] Theorem 16.6 Tutte's 1-Factor Theorem
>A graph $G$ has a perfect matching if and only if $o(G - S) \le |S|$ for all $S \subseteq V$, where $o(G-S)$ is the number of odd components of $G-S$.

>[!tips] Theorem 16.12 Petersen's Theorem
>Every cubic bridgeless graph has a perfect matching (actually, a sum of 1-factors).
