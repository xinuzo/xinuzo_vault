>[!tips] Bound 14.3
>$\chi(G) \le \Delta(G) + 1$.

>[!tips] Theorem 14.4 Brooks' Theorem
>If $G$ is connected and neither an odd cycle nor a complete graph, then $\chi(G) \le \Delta(G)$.

>[!tips] Theorem 14.5 Gallai-Roy Theorem
>Every digraph $D$ contains a directed path with $\chi(D)$ vertices.

>[!tips] Theorem 14.10 Girth and Chromatic Number
>For any $k$, there exists a graph with girth at least $k$ and chromatic number at least $k$. (Proven via probabilistic method).
>Constructive proof: **Mycielski's Construction** produces triangle-free $k$-chromatic graphs.

>[!tips] Theorem 14.12 Perfect Graph Theorem
>A graph is perfect if and only if its complement is perfect. (Lovász, 1972).

>[!tips] Theorem 14.13 Strong Perfect Graph Theorem
>A graph is perfect if and only if it contains no induced odd cycle of length $\ge 5$ or its complement. (Chudnovsky et al., 2006).

>[!tips] Theorem 14.19 Five-Colouring Lists
>Every planar graph is 5-list-colourable. (Thomassen, 1994).
