>[!tips] 14.1 Chromatic Number $\chi(G)$
>The minimum number of colours needed to colour the vertices of $G$ such that no two adjacent vertices receive the same colour.

>[!tips] 14.2 Critical Graph
>A graph $G$ is $k$-critical if $\chi(G) = k$ and $\chi(H) < k$ for every proper subgraph $H$.

>[!tips] 14.4 Perfect Graph
>A graph $G$ is perfect if $\chi(H) = \omega(H)$ for every induced subgraph $H$.

>[!tips] 14.5 List Colouring
>$G$ is $k$-list-colourable if for any assignment of lists of size $k$ to vertices, there exists a proper colouring where each vertex chooses a colour from its list. $\chi_L(G)$ is the list chromatic number.

>[!tips] 14.7 Chromatic Polynomial
>$P(G, x)$ counts the number of proper colourings of $G$ with $x$ colours.
