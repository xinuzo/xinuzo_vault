>[!tips] Theorem 17.1 König's Theorem
>Every bipartite graph is Class 1. That is, $\chi'(G) = \Delta(G)$ if $G$ is bipartite.

>[!tips] Theorem 17.2 Vizing's Theorem
>For any simple graph $G$:
>$$\Delta(G) \le \chi'(G) \le \Delta(G) + 1$$

>[!tips] Theorem 17.4 Shannon's Bound
>For any multigraph $G$, $\chi'(G) \le \frac{3}{2}\Delta(G)$.

>[!tips] Theorem 17.6 Tait's Theorem (Edge Colouring)
>A cubic map is 4-colourable (faces) if and only if its underlying graph is 3-edge-colourable (Tait colouring).
