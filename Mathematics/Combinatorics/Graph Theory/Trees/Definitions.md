>[!tips] 4.1 Tree, Forest
>A connected acyclic graph is a tree. An acyclic graph is a forest (a disjoint union of trees).

>[!tips] 4.1 Leaf
>A vertex of degree one in a tree is called a leaf.

>[!tips] 4.1 Rooted Tree, Branching
>A rooted tree $T(x)$ is a tree with a specified root $x$. An orientation of a rooted tree where every vertex but the root has indegree one is a branching.

>[!tips] 4.1 Median Order
>A median order of a digraph $D$ is a linear order $v_1, \dots, v_n$ of $V$ such that the number of arcs directed from left to right ($i < j$) is maximized.
