>[!tips] Proposition 4.1 Unique Path
>In a tree, any two vertices are connected by exactly one path.

>[!tips] Proposition 4.2 Leaves
>Every nontrivial tree has at least two leaves.

>[!tips] Theorem 4.3 Tree Size
>If $T$ is a tree, then $e(T) = v(T) - 1$.

>[!tips] Theorem 4.4 Reachability
>Let $x$ be a vertex of a digraph $D$, and $X$ the set of vertices reachable from $x$. Then there is an $x$-branching in $D$ with vertex set $X$.

>[!tips] Theorem 4.5 Branchings in Tournaments
>Any tournament on $2k$ vertices contains a copy of each branching on $k+1$ vertices.

>[!tips] Theorem 4.6 Spanning Trees
>A graph is connected if and only if it has a spanning tree.
