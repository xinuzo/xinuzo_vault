>[!tips] Theorem 2.1 Properties of Composition
>Assume that $\alpha: S \to T$ and $\beta: T \to U$.
>(a) If $\alpha$ and $\beta$ are onto, then $\beta \circ \alpha$ is onto.
>(b) If $\beta \circ \alpha$ is onto, then $\beta$ is onto.
>(c) If $\alpha$ and $\beta$ are one-to-one, then $\beta \circ \alpha$ is one-to-one.
>(d) If $\beta \circ \alpha$ is one-to-one, then $\alpha$ is one-to-one.

>[!tips] Theorem 2.2 Invertibility Condition
>A mapping is invertible iff it is both one-to-one and onto.
>Note: If a mapping is invertible, its inverse is unique.

>[!tips] Theorem 4.1 Composition on $M(S)$
>Let $S$ denote any nonempty set.
>(a) Composition is an associative operation on $M(S)$ (the set of all mappings from $S$ to $S$), with identity element $\iota_S$.
>(b) Composition is an associative operation on the set of all invertible mappings in $M(S)$, with identity $\iota_S$.

>[!tips] Property: Invertible Mappings Group
>The set of all invertible mappings in $M(S)$ is closed with respect to composition, and the inverse of an invertible mapping is invertible. (From proof of Thm 4.1)

>[!tips] Property: Composition in $M(S)$
>If $|S| > 1$, then composition is not a commutative operation on $M(S)$. (Problem 4.10)
