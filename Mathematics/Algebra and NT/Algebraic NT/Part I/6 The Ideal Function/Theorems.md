# Theorems - Chapter VI: The Ideal Function

## §3. The Number of Ideals

>[!tips] 6.3 Theorem 2
>Let $\kappa$ be the residue of the zeta function at $s=1$. The number of ideals in a given ideal class with norm $\le x$ is asymptotic to $\kappa x$ as $x \to \infty$.
>$$\kappa = \frac{2^{r_1} (2\pi)^{r_2} R_k}{w \sqrt{|D_k|}}$$
>where $w$ is the number of roots of unity in $k$.
