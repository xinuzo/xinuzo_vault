>[!tips] 52.1 Constructible Number
>A real number is constructible if it can be constructed from the integers 0 and 1 using a finite number of steps with a straightedge and compass. Algebraically, this corresponds to forming a sequence of field extensions $F_0 \subseteq F_1 \subseteq \dots \subseteq F_k$ where each $[F_i : F_{i-1}] = 2$.
