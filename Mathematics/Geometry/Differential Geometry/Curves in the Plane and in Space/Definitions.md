>[!tips] 1.1 Parametrized Curve
>A parametrized curve in $\mathbb{R}^n$ is a map $\gamma: (\alpha, \beta) \to \mathbb{R}^n$ (where $\alpha, \beta$ can be infinite).
>$\gamma(t) = (x(t), y(t))$ for plane curves.

>[!tips] 1.1 Level Curve
>A curve defined by an equation of the form $f(x, y) = c$, where $f$ is a function of two variables and $c$ is a constant.

>[!tips] 1.3 Tangent Vector
>If $\gamma(t)$ is a curve, $\dot{\gamma}(t) = \frac{d\gamma}{dt}$ is the tangent vector at $\gamma(t)$.

>[!tips] 1.3 Regular Curve
>A curve $\gamma$ is regular if $\dot{\gamma}(t) \neq \mathbf{0}$ for all $t$. (This ensures the tangent line is well-defined).

>[!tips] 1.3 Reparametrization
>A reparametrization of $\gamma: (\alpha, \beta) \to \mathbb{R}^n$ is a map $\tilde{\gamma}: (\tilde{\alpha}, \tilde{\beta}) \to \mathbb{R}^n$ given by $\tilde{\gamma}(u) = \gamma(\phi(u))$, where $\phi: (\tilde{\alpha}, \tilde{\beta}) \to (\alpha, \beta)$ is a smooth bijective map with smooth inverse.
