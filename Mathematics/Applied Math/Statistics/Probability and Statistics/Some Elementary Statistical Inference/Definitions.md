>[!tips] 4.1 Statistic and Point Estimator
>A function of the sample data that does not depend on unknown parameters is called a statistic. [cite_start]A statistic used to estimate a parameter is called a point estimator. [cite: 92]

>[!tips] 4.1 Unbiased Estimator
>[cite_start]An estimator $\hat{\Theta}$ of a parameter $\theta$ is unbiased if $E(\hat{\Theta}) = \theta$. [cite: 39]

>[!tips] 4.2 Confidence Interval
>[cite_start]A confidence interval for $\theta$ with confidence coefficient $1-\alpha$ is a random interval $(L, U)$ such that $P(L < \theta < U) = 1-\alpha$. [cite: 92]

>[!tips] 4.4 Order Statistics
>[cite_start]For a random sample $X_1, ..., X_n$, the order statistics are the sample values sorted in ascending order, denoted by $Y_1 < Y_2 < ... < Y_n$. [cite: 92]

>[!tips] 4.5 Hypothesis Testing
>A statistical hypothesis is an assertion about the distribution of a random variable.
>- **Null Hypothesis ($H_0$)**: The hypothesis to be tested (usually "no effect").
>[cite_start]- **Alternative Hypothesis ($H_1$)**: The hypothesis against which $H_0$ is tested. [cite: 92]

>[!tips] 4.5 Errors in Testing
>- **Type I Error**: Rejecting $H_0$ when it is true. The probability is denoted by $\alpha$ (significance level).
>- **Type II Error**: Failing to reject $H_0$ when it is false. [cite_start]The probability is denoted by $\beta$. [cite: 92]

>[!tips] 4.6 p-value
>[cite_start]The p-value is the probability, computed assuming $H_0$ is true, of observing a test statistic at least as extreme as the value actually observed. [cite: 92]

>[!tips] 4.9 Bootstrap
>[cite_start]A resampling method used to estimate the sampling distribution of a statistic by repeatedly sampling with replacement from the observed data. [cite: 92]
